PC 용도별 부품 매칭 로직

	Default
		
		RAM은 듀얼채널로 구성
		가성비
			ram 클럭은 cpu 공식 지원 클럭과 비슷하게(최소 5600)
			psu 등급 Bronze ~ Silver
		성능
			ram 클럭 6000~6400MHz(예산에 따라 변동), cpu의 공식 지원 클럭보다 많게 여유분 유지
			psu Gold 등급 이상
			

	1. 문서작업
		CPU - i3 전체/i5-13400급 부터 (단, 내장 gpu보유 부품으로 한정 매칭)
		GPU - 매칭 안함
		RAM - 16gb 이상
		SSD - 512gb 이상
		HDD - 요구사항 없음
		
		

	2. 영상편집
		CPU - i5-K/Ultra5급 이상
		GPU - RTX 5060Ti급 이상
		RAM - 32gb 이상
		SSD - 1tb 이상
		HDD - 2tb 이상
	
	
	3. 3D 렌더링/모델링 
		GPU(최우선 주요 부하 지점) - VRAM 16gb 이상 필수
			가성비 : RTX 4060Ti 16gb / RTX 4070 12gb / RTX 5060 12gb
			성능 : RTX 4070 Ti Super 16GB or RTX 4090 24GB / RTX 5080 16GB~24GB
		CPU
			가성비 : 6코어 12스레드 ~ 8코어 16스레드(ex. 인텔 i5-14400 / Core Ultra 5, i7-14700K / Core Ultra 7)
			성능 : 12코어 20스레드 ~ 16코어 32스레드(ex. 인텔 i9-14900K / Core Ultra 9, AMD 라이젠 9 7900X / 7950X)
		RAM - 64gb 이상
		SSD - DRAM 탑재, PCIe 4.0/NVMe 필수
			가성비 : 1tb
			성능 : 2tb
		HDD - 4tb 이상
		쿨러 - i7/i9중 K모델일 경우 3열 수랭식 쿨러 강제

	4. 방송/스트리밍
		GPU(최우선 주요 부하 지점) : RTX 40/50 시리즈
			가성비 매칭 : RTX 4060/ RTX 5060 VRAM 8gb
			성능 매칭 : RTX 4070 / RTX 4070 Ti S / RTX 5070 or RTX 4080 S / RTX 4090 / RTX 5080, VRAM 12~16gb
		CPU - RTX 4070Ti급 이상
		RAM - 32gb 이상
		SSD - 1tb 이상
		HDD - 해당사항 없음
		
	5. 개발/컴파일 
		CPU - i5-13600/Ultra5급 이상
		GPU - RTX 5050급 이상 (일반 개발 기준 - AI/딥러닝용 고VRAM 요구는 아직 미분리)
		RAM - 32gb 이상
		SSD:DRAM 탑재
			가성비 : 1tb
			성능 : 2tb
		HDD - 해당사항 없음
		
	6. 게임
		CPU/GPU - 게임별 테이블에 저장된 값 사용
		SSD
			가성비 : 1tb, PCIe 4.0 NVMe
			성능 : 2tb, PCIe 4.0 NVMe/DRAM 포함
		HDD - 1tb
			

부품 매칭 순서
	CPU/GPU -> 메인보드 -> RAM -> 쿨러 -> PSU -> 케이스 -> (저장장치의 경우 별도) -> Gemini 최종 검수(물리적 매칭 불가능 여부 등 판단)
	

1. CPU / GPU
	- 부품 밸런스간 병목 현상이 생기지 않도록 성능 등급의 격차가 지나치게 크지 않아야함
	- 작업 용도나 환경에 따라 차이가 존재할 수 있음(용도별 주요 부하 지점의 차이)
	
2. 메인보드
	- 소켓 규격 일치 : CPU 소켓 규격과 메인보드의 cpu 소켓 규격이 동일해야 함
	- 메인보드 최대 메모리 지원 속도(MHz) >= RAM 동작 클럭(MHz) (PC 용도,가성비/성능 선택 옵션에 따라 선택)
	- 슬롯 수량 : 메인보드 RAM 슬롯 개수 >= 장착할 RAM 모듈 수량(해당 프로젝트에선 듀얼채널 RAM만 취급하기 때문에 미일치 상황은 없다고 전제한다)
	
3. RAM
	- 메인보드 지원 메모리 규격 = RAM 규격(DDR4/DDR5)
	- 메인보드 최대 메모리 속도 (MHz)>=RAM 동장 클럭(MHz)
	- RAM 두께 < GPU 및 CPU 공랭 쿨러 하단 간의 공간 (해당 내용은 물리적인 치수가 따로 존재하지 않기 때문에
		RGB RAM/RAM 상단에 방열판이 존재할 때 해당 수치가 35mm를 넘어가며 듀얼타워 공랭쿨러를 매칭할 경우
		물리적인 충돌이 일어날 가능성이 존재함. 해당 경우는 텍스트로 경고메세지를 출력하는 기능만 추가)

4. 쿨러
	- 쿨러의 TDP >= CPU 최대 터보 전력(MTP) * 1.3
	- 마운팅 소켓 지원 : 쿨러의 cpu 규격 = CPU 소켓
	
	
5. PSU
	- 정격 출력 용량 : PSU 정격 용량(W) >= (CPU MTP + GPU MTP + 기타 부품 50W)*1.3
	- 품질 인증 등급 : PC 용도에 따라 최소 80PLUS Bronze ~ 80PLUS Gold 선택)


6. 케이스
	- 공랭 쿨러 : 케이스 스펙 상 최대 CPU 쿨러 장착 높이(mm) > 공랭 쿨러 전체 높이(mm)
	- 수랭 쿨러 : 라디에이터 표준 규격 <= 케이스 장착 위치 별(상단/측면/후면) 최대 지원 라디에이터 규격
	- (수랭 쿨러의 장착 방향이 전면부 한정일 경우) : 케이스 최대 GPU 지원 길이 - 팬두께(약 55mm)>=GPU 전체 길이
	- GPU 케이스 공간 : 케이스 장착 가능 최대 VGA 길이(mm) > GPU 실제 전체 길이(mm)
	- PSU 폼펙터 : 케이스 지원 PSU 규격(표준 ATX, SFX 등) >= PSU 외형 규격
	- 폼펙터 규격 : 케이스 지원 폼펙터 >= 메인보드 폼펙터(ATX 케이스 -> ATX/m_ATX/ITX 장착 가능, M-ATX 전용 케이스 -> 표준 ATX 메인보드 장착 불가)

7. M.2 NVMe SSD
	- 메인보드 M.2 슬롯 세로 길이 규격 = M.2 SSD 폼펙터 길이(ex. 메인보드 220 지원규격 = SSD 2280규격(22mm*80mm))
	- 메인보드 M.2 슬롯 지원 프로토콜 = M.2 SSD 신호 방식(NVMe/SATA)
	- 메인보드 M.2 PCIe 버전 >= M.2 SSD PCIe 버전
	
8. SATA SSD / HDD
	- 메인보드 남아있는 SATA3 포트 개수 >= 장착할 SATA SSD/HDD 개수
	- 케이스 내부 장착 베이 수량 >= 장착할 2.5인치 SSD + 3.5인치 HDD 개수
	- PSU SATA 전원 케이블 커넥터 개수 >= 장착할 SATA 장치 개수
